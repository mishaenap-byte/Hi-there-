# Админка Hi There — настройка (один раз)

Админку видит только автор: строка «📊 Админка» появляется в профиле, только если сервер подтвердил, что вы — админ.
Данные о людях отдаёт функция `admin` с ключом сервиса; из приложения чужие данные прочитать нельзя.

1. **Таблицы.** Supabase → SQL Editor → вставить `supabase/admin.sql` → Run.
   Если раньше запускали `tutor.sql`, таблицы уже есть — повторный запуск ничего не ломает.
2. **Функция.** Supabase → Edge Functions → Deploy a new function → Via Editor.
   В поле имени впишите ровно `admin` (адрес должен получиться …/functions/v1/admin), вставьте `supabase/functions/admin/index.ts` → Deploy.
   Затем в настройках функции выключите **Verify JWT** (функция сама проверяет вход).
3. **Кто админ.** Используется тот же секрет `PUSH_ADMINS`, что и для рассылки уведомлений (ваш user id).
   Можно вписать туда и email через запятую. Другой список — секрет `ADMINS`.

Что видно: кто онлайн сейчас, сколько зашли и зарегистрировались сегодня, таблица людей (вход, уровень, серия, уроки и шаги курса, число слов, XP), возвраты на 1-й и 7-й день, карточка человека с календарём входов.
Что не видно: слова из словаря, сообщения, посты — только счётчики.
