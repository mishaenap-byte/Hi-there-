# Пуш-уведомления Hi There: как включить

Всё делается в панели Supabase (проект `jdpreowtaahhqaalzhgi`) и один раз. Мне ключи присылать не нужно.
Не нажимайте «Copy all» в окне Connect.

## 1. Таблица для подписок
SQL Editor → New query → вставьте содержимое `push.sql` → Run.

## 2. Функция-отправщик
1. Edge Functions → **Deploy a new function** → **Via Editor**.
2. Имя функции: `push-send`. Вставьте весь код из `functions/push-send/index.ts` → **Deploy**.
3. Откройте функцию → **Details** (или Settings) → выключите **Verify JWT** (Enforce JWT verification) → Save.
   Функция сама проверяет, кто её вызывает: это нужно, чтобы её мог вызвать браузер (шаг 3) и расписание (шаг 6).

## 3. Ключи уведомлений
Откройте в браузере:
`https://jdpreowtaahhqaalzhgi.supabase.co/functions/v1/push-send?mode=keygen`
Появятся два ключа: `VAPID_PUBLIC_KEY` и `VAPID_PRIVATE_KEY`. Окно не закрывайте до шага 4.

## 4. Secrets
Edge Functions → **Secrets** → добавьте пять строк:

| Имя | Значение |
|---|---|
| `VAPID_PUBLIC_KEY` | первый ключ из шага 3 |
| `VAPID_PRIVATE_KEY` | второй ключ из шага 3 (секретный, никому не отправляйте) |
| `VAPID_SUBJECT` | `mailto:` и ваша почта, например `mailto:you@gmail.com` |
| `CRON_KEY` | любой длинный набор букв и цифр, придумайте сами |
| `PUSH_ADMINS` | ваш id: Authentication → Users → ваша строка → скопируйте **UID** |

После этого ссылка из шага 3 будет отвечать «Ключи уже заданы» — так и должно быть.

## 5. Сайт
Загрузите новый `hi-there-site.zip` на Netlify.
На iPhone откройте Hi There **с экрана «Домой»** → Профиль → **🔔 Напоминания** → «Разрешить».
Там же у вас появится **📣 Отправить уведомление всем** — это ваша рассылка.

## 6. Вечернее напоминание по расписанию
1. Database → **Extensions** → включите `pg_cron` и `pg_net` (если они уже включены — пропустите).
2. SQL Editor → вставьте `push-cron.sql`, замените `ВАШ_CRON_KEY` на значение из шага 4 → Run.

Каждый день в 19:00 (Кишинёв, летнее время) придёт «Пора повторить N слов» тем, у кого есть слова на сегодня
в интервальном повторении. Если слов на сегодня нет, но есть очередь — «Новые слова ждут». Остальным ничего не приходит.

## Если что-то не так
- Нет строки «Напоминания» на iPhone: приложение открыто во вкладке Safari, а не с экрана «Домой», или iOS старше 16.4.
- «Не получилось включить уведомления»: проверьте шаги 2–4 (функция задеплоена, Verify JWT выключен, ключи в Secrets).
- Уведомления выключены в Настройки iPhone → Hi There → Уведомления.
