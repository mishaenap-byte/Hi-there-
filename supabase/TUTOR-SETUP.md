# ИИ-репетитор Hi There: как включить (этап 0)

Всё делается один раз в панели Supabase (проект `jdpreowtaahhqaalzhgi`). Ключи мне присылать не нужно: они живут только в Secrets Supabase, в приложении их нет.

## 1. Ключи (делаете вы)
1. **OpenAI**: platform.openai.com → API keys → Create new secret key. Пополните баланс на $5–10. Нужен для голоса (gpt-4o-mini-tts, голос Alloy) и распознавания (gpt-4o-transcribe).
2. **Gemini**: aistudio.google.com → Get API key → Create API key. Это «мозги» репетитора (Gemini Flash).
3. По желанию **ElevenLabs** (бесплатный аккаунт): elevenlabs.io → Profile → API keys. Нужен только чтобы на этапе 1 сравнить распознавание Scribe с OpenAI.

## 2. Таблицы
SQL Editor → New query → вставьте весь файл `tutor.sql` → Run.
Повторный запуск ничего не ломает.

## 3. Функция
1. Edge Functions → **Deploy a new function** → **Via Editor**.
2. Имя: `tutor`. Вставьте весь код из `functions/tutor/index.ts` → **Deploy**.
3. Откройте функцию → Details → выключите **Verify JWT** → Save (функция сама проверяет, кто вошёл).

## 4. Secrets
Edge Functions → **Secrets** → добавьте:

| Имя | Значение |
|---|---|
| `OPENAI_API_KEY` | ключ OpenAI из шага 1 |
| `GEMINI_API_KEY` | ключ Gemini из шага 1 |
| `ELEVENLABS_API_KEY` | по желанию, ключ ElevenLabs |

Ваш id владельца уже лежит в `PUSH_ADMINS` (из настройки уведомлений) — админка возьмёт его оттуда. Если его нет, добавьте `TUTOR_ADMINS` = ваш UID (Authentication → Users → ваша строка).

Необязательные настройки (можно не трогать):

| Имя | Что меняет | По умолчанию |
|---|---|---|
| `GEMINI_MODEL` | модель репетитора | `gemini-3.8-flash` (если Google её закроет, функция сама возьмёт `gemini-flash-latest`) |
| `ANALYZER_MODEL` | модель аналитика ошибок | как `GEMINI_MODEL` |
| `REALTIME_MODEL` | модель «⚡ Быстрого режима» (необязательно) | `gpt-realtime-2.1-mini`; если её нет — функция сама берёт `gpt-realtime-mini`, `gpt-realtime-2.1`, `gpt-realtime` |
| `TUTOR_STT` | распознавание: `openai` или `scribe` | `openai` |
| `TUTOR_FREE_LESSONS` | бесплатных уроков | `2` |
| `TUTOR_DAILY_VOICE_MIN` | минут голоса в день, дальше текст | `60` |
| `TUTOR_ALERT_DAY_USD` / `TUTOR_ALERT_USER_USD` | пороги тревоги в админке | `10` / `3` |

## 5. Сайт
Загрузите новый `hi-there-site.zip` на Netlify. На iPhone откройте Hi There → Упражнения → **🎙 ИИ-репетитор**.

## 6. Этап 1 — проверка «голос туда-обратно»
Профиль → **📊 Админка** → вкладка **Тесты**:
- «Этап 1»: зажмите кнопку у каждой из 10 фраз и прочитайте её с ошибкой. Зелёное — распознавание записало дословно, красное — «исправило». Если добавлен ключ ElevenLabs, рядом будет результат Scribe. Лучший выбираете секретом `TUTOR_STT`.
- «Этап 2»: кнопка прогоняет те же 10 ошибок через 2–3 модели и показывает, сколько поймала каждая и цену за урок. Цель — 8 из 10.
- Потом проведите обычный урок и послушайте голос: пауза перед ответом ≈ 2 с, голос звучит хорошо по-английски и по-русски.

## ⚡ Быстрый режим (OpenAI Realtime)
Переключатель на главной репетитора. Телефон говорит с OpenAI напрямую, без кнопки: ответ начинается почти сразу, перебить можно голосом.
- Нужен тот же `OPENAI_API_KEY`, отдельный ключ не нужен. Функция выдаёт телефону **временный** ключ на один урок; настоящий ключ остаётся в Secrets.
- Реплики сохраняются в базу как обычно, поэтому разбор, домашка, память и план работают так же.
- Стоимость: примерно $0.03–0.06 за минуту на mini-модели (обычный режим дешевле). Видно в админке, строка `realtime`.
- Ошибка «Быстрый режим: …» в приложении показывает ответ OpenAI как есть; урок тогда сам продолжается в обычном режиме.

## Доступ и бета (этап 6–7)
Каждому дано 2 бесплатных урока. Для беты: Админка → Люди → тап по человеку → «Бета» — уроки без ограничения (страховка 60 минут голоса в день остаётся). Оплаты в приложении пока нет, цены ($9.99 / $59.99) показываются на экране «Пробные уроки закончились».

## Если что-то не так
- «Функция tutor ещё не установлена» — шаг 3 не сделан или функция названа иначе.
- «Не задан OPENAI_API_KEY / GEMINI_API_KEY» — шаг 4.
- «Нужно войти в аккаунт» — Verify JWT не выключен (шаг 3.3) или вы не вошли.
- Голос не звучит на iPhone — выключен звук кнопкой сбоку или режим «Без звука».
